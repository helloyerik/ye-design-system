# i18n

- English is the default and the key source (`en` catalog). Russian is the secondary `ru` catalog, used only when the user picks it.
- Web: `createT({ en, ru }, pickLocale(stored))` from `@yeds/ui-react/i18n`. Placeholders `{name}`, plurals through `Intl.PluralRules` (ru one/few/many). Missing keys fall back to `en`, then to the key. `missingKeys()` is meant for a CI check.
- Compose: `res/values/strings.xml` (en) + `values-ru/strings.xml`, with lint `HardcodedText` as an error.
- Backends return ids (e.g. genre `phonk`), not display text.
- Status 2026-10-15: yephotos UI copy is already English (Cyrillic only in comments and in the functional Takeout matchers). Its strings are not extracted into catalogs yet.
